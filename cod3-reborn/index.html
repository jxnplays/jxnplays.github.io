What is COD3 Reborn?

A continuation of the XenonRecomp static recompilation of Call of Duty 3 (Xbox 360). The original game never had a PC release. This project gives it one — cleanly, legally, and under our full control.

Native Port

PowerPC → C++ → native x86-64. No emulator. The game runs as ordinary Windows code with a D3D11 renderer that executes the title’s own shaders.

Full Host Control

We own the runtime: memory, input, rendering, asset streaming, and kernel stubs. Everything new is built on the host side in Rust.

Clean Legal Path

Users supply their own ISO. We distribute only tools, host code, and documentation. No original assets are shipped.

Call of Duty 3 Zombies

A real round-based Zombies mode built on the host. Systems drawn from Modern Operations (COD4) and MW2: Reimagined — proven pathfinding, barriers, and loops that never existed in COD3.

Modding Infrastructure

COD3 has zero public tools. We build the first ones.

Host Hooks

Documented access to health, ammo, position, damage, and weapon events. Config-driven god mode, infinite ammo, noclip.

Asset Tools

Texture extractor/replacer, audio tools, and eventually model export. One working custom loadscreen as the first example.

Custom Maps

Defined archive format for community arenas. Packer tools and a path to load maps the host understands.
