What is MWS&BOX?

An open sandbox built on the latest upstream IW4L client. It does not ship or download game files. It reads legitimate installs you already have and adds per-game asset support over time so content from those installs can load and play inside one client. Also includes content from the IW4L mashup fork (Skate 3 and Minecraft).

Goals

  • Maintain a clean, regularly updated IW4L base as the single foundation for every title
  • Build and maintain readers and converters so each of the 12 target games can contribute its maps, guns, attachments, camos, perks, and modes
  • Make imported content feel native — correct models, viewmodels, sounds, animations, stats, and attachment behavior where the data allows
  • Full support for IW4X and Plutonium-compatible mods so existing community work continues to load
  • Keep the project open so contributors can claim individual titles, readers, or feature areas without overlapping
  • Document progress clearly so anyone can see what is working, what is blocked, and where help is needed
  • Ship a single client that can load content from any of the 12 titles you own

How it stays focused

The project is intentionally limited to 12 titles. We are not attempting the entire Call of Duty series. New games are only added when the technical path is realistic and someone is willing to own the reader, converter, and integration work for that title. MW2 remains the required base; everything else is optional and only contributes its own content. Parallel recomp projects (NX1 Reborn, COD3 Reborn, CODOL Reborn) feed assets into the same client without expanding the core scope.

Mod Support

IW4X and Plutonium mods are supported. Drop compatible mods into the client the same way those projects expect.

Full support for IW4X-compatible mods, maps, and scripts.

Plutonium mod formats and loaders are supported where they overlap with the IW4L runtime.

How it works

1. Own the game

Legal Steam (or equivalent) install. The client does not ship or download game files.

2. Point at the folder

Modern Warfare 2 is required. Other games are optional and only contribute their own maps, weapons, and modes.

3. Play what loads

Built on the latest upstream IW4L. Asset readers and converters are added per game as work progresses.

Want to help?

The main client is being restructured around a clean latest-upstream IW4L base with per-game trackers. NX1, COD3, and Call of Duty Online work continue in parallel. Other titles are open.
