One client. Every Call of Duty you own.

A maintained IW4L-based runtime that reads the games you already have installed. Modern Warfare 2 is required. Everything else is optional and only adds what that install contains.

How it works

1. Own the game

Legal Steam (or equivalent) install. The client does not ship or download game files.

2. Point at the folder

Modern Warfare 2 is required. Other games are optional and only contribute their own maps, weapons, and modes.

3. Play what loads

Built on the latest upstream IW4L. Asset readers and converters are added per game as work progresses.

Want to help?

The main client repo is being restructured around a clean latest-upstream IW4L base with per-game trackers. NX1 and COD3 work continue in parallel. Other titles are open.
