One client for 12 Call of Duty titles.

A maintained IW4L-based sandbox that loads maps, weapons, attachments, and modes from the games you already own. Focused on a fixed set of 12 titles from COD3 through Infinite Warfare, plus Future Warfare (NX1) and Call of Duty Online. Modern Warfare 2 is required. Everything else is optional.

What is MWS&BOX?

An open sandbox built on the latest upstream IW4L client. It does not ship or download game files. It reads legitimate installs you already have and adds per-game asset support over time so content from those installs can load and play inside one client.

Goals

  • Keep a clean, up-to-date IW4L base as the foundation
  • Build readers and converters so each target game can contribute its maps, guns, attachments, camos, and modes
  • Get content feeling native — correct models, sounds, animations, and stats where possible
  • Support IW4X and Plutonium-compatible mods
  • Open the project so others can claim and work on individual titles

How it stays focused

We are not targeting the entire Call of Duty series. The current list is fixed at 12 titles. New games are only added when the work is realistic and someone is willing to own the reader and asset path for that title.

How it works

1. Own the game

Legal Steam (or equivalent) install. The client does not ship or download game files.

2. Point at the folder

Modern Warfare 2 is required. Other games are optional and only contribute their own maps, weapons, and modes.

3. Play what loads

Built on the latest upstream IW4L. Asset readers and converters are added per game as work progresses.

Want to help?

The main client is being restructured around a clean latest-upstream IW4L base with per-game trackers. NX1, COD3, and Call of Duty Online work continue in parallel. Other titles are open.
