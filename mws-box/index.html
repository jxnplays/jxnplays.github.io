FEATURES

THE SANDBOX.

A Rust and Bevy client. It reads the games you own. It does not ship them. Graphics marked planned are on the board, not in a match yet.

YOUR FILES

Point it at the Steam folder. It reads the fastfiles there. It does not download or replace them.

ONE LOBBY

Fourteen games in one client. Modern Warfare 2 is the base. The rest add only what that install contains.

CREATE A CLASS

Guns, equipment, perks, and deathstreaks, split by game, plus an All list. Modern Warfare 2, 3, and Black Ops are the first three.

MATCH TYPES

Only the modes that game shipped. Third Person is the SOCOM-style camera. Hardcore and Old School are rules.

AMBIENT OCCLUSION PLANNED

Contact shadow in corners and under cover. A video setting, not a baked look.

WATER PLANNED

A new water shader for maps that have it. Reflection and motion, not the flat retail sheet.

WEATHER PLANNED

Rain, fog, and clear. The options menu can list them. The world effect is still to be wired.

LIGHT AND SHADOW PLANNED

Sun direction, shadow quality, and a night pass. Per map, not one global grade.

HOW IT WORKS

POINT IT AT WHAT YOU OWN.

No installer for the games. The client reads the folder you already have.

1. Own the game.

A legal Steam install. Modern Warfare 2 is the one the client needs.

2. Point at the folder.

The client reads that install. It does not download or replace the game files.

3. Add the rest.

Each other game is optional. It adds only the maps, guns, and modes that install contains.
