Modern Warfare Sandbox is a fan client for the line from Call of Duty 1 through WWII. Modern Warfare 2 is the base. Every other game is optional, and adds only what that install contains.

EVERYTHING YOU BROUGHT IN.

Guns, attachments, perks, camos, emblems, calling cards, titles, and clan tags, where that game had them. Early games did not have a class screen. Those stay maps and guns.

MODES

PICK A FIGHT.

MULTIPLAYER

A private match on the map you picked, from the game you picked.

CAMPAIGN

Each game's story, kept as its own mode.

ZOMBIES

World at War, Black Ops, Black Ops 2, Black Ops 3, Infinite Warfare.

SPEC OPS

Modern Warfare 2 and 3. Survival beside them.

EXTINCTION

Ghosts, as its own mode.

HEADQUARTERS

A room between matches. The WWII headquarters, and the rooms like it.

REQUIREMENTS

BRING YOUR OWN GAMES.

No game data is distributed here. Modern Warfare 2 is required. The others are optional. A line is listed only if that game shipped it.
